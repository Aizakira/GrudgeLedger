Grudge Ledger 0.5.2 — sources et tests

Le dossier GrudgeLedger est le seul dossier à installer dans Interface/AddOns.
Les tests utilisent Lua 5.1 via Lupa, sans lancer WoW.
Depuis ce dossier :
  python -m pip install --target test-runtime -r requirements-test.txt
  python tests/run_tests.py

Le runtime de test ne fait pas partie de l’addon.
Aucune donnée SavedVariables n’est incluse.
Les noms et identifiants des tests sont des exemples simulés.
Les icônes, clics, sons et API effectives doivent aussi être vérifiés dans WoW.

Revue visuelle facultative hors jeu (Windows, polices Arial/Georgia) :
  python -m pip install Pillow==12.1.1
  python visual-qa/render.py
Le rendu provient des cadres Lua réels exécutés avec des API simulées.
Polices/textures natives approximées ; exemples fictifs, aucune capture du jeu.

Le renderer vérifie 27 vues (dont les deux styles de police) : états rempli, filtré, vide, petit écran, bas de
défilement, texture du livre absente, toutes les textures de parchemin absentes, fenêtres secondaires, minimap et alertes. La vue journal-transparent exporte
un PNG détouré et un aperçu sur damier clair ; elle vérifie les coins transparents
et l'absence de peinture au-delà du livre. Il échoue si un contrôle
se chevauche, dépasse la fenêtre ou si le texte dépasse sa région. Le workflow
Windows exécute aussi cette vérification. Ces mesures ne remplacent pas une
revue esthétique ni un essai dans le client réel.

Détecteur druide, état au 11 novembre 2026
----------------------------------------
Le curseur virtuel (/glprobe test) a rendu un résultat négatif sur le vrai
client 70888. Il reste disponible comme contrôle, mutuellement exclusif avec
/glradar test. La nouvelle expérience est une machine à états bornée :
point vide -> grille 15x15 -> point vide -> relecture du témoin -> point vide.
Chaque lecture attend deux OnUpdate ; la limite globale est de 12 secondes.
Les tests ne prétendent pas simuler le moteur natif : ils modélisent les noms
à partir de la géométrie carte/curseur, avec une latence de rendu de 1/2 images.
Une réussite locale valide le protocole, pas la disponibilité du moteur WoW.

19 scripts de tests, dont 73 cas du détecteur druide : API absentes/protégées,
cache trompeur, correspondance exacte et ambiguïtés, propriétaire d'un familier,
relecture absente, échelles et dimensions différentes, timeout, interruptions,
erreur à chaque mutation et restauration (y compris un setter sans effet),
exclusion mutuelle, persistance bornée et absence d'identités dans le rapport.
Le masque TGA de 8x8 pixels est contrôlé : transparent, sans image tierce.

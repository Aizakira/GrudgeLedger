Menu integration and nameplate/tooltip lifecycle techniques are adapted from
Worth Remembering by Kyle (maliceftw), licensed under GPLv3:
https://github.com/kk-on-gh/WorthRemembering
https://www.curseforge.com/wow/addons/worth-remembering
Attributions for adapted portions are retained in source file headers.

The PvP inference module is independently implemented. Its approach was informed
by Grudgebook's documented use of observable units, targets and honor signals:
https://www.curseforge.com/wow/addons/grudgebook
Grudgebook's addon files are not bundled and it is not a runtime dependency.

The borderless minimap book (Media/LedgerBook.tga) uses the client's native
minimap ring. The JournalMedallion texture includes an illustrated brass ring
and is used on the journal. Both illustrations were generated for this addon
using OpenAI's image tool and are distributed under GPLv3.

The relationship markers (Media/RelationFriend.tga, RelationWarning.tga and
RelationEnemy.tga) were generated and edited using the same OpenAI tool: a green
heart, an orange watchful eye and a red broken heart. They are included as
uncompressed 128x128 RGBA TGA textures under the same GPLv3 terms.
Other icons and sounds are referenced from the player's installed World of
Warcraft client. No Blizzard media files are redistributed in this package.
World of Warcraft is a trademark of Blizzard Entertainment.

The kiss action icon (Media/GestureKiss.tga, 128x128 opaque RGBA) was generated
with OpenAI's built-in image tool: painted red lips blowing a small pink heart.
It is original artwork, distributed under the same GPLv3 terms, and uses the
native client button frame. No Blizzard artwork was copied into this texture.

No personal player database or guild list is distributed with this addon.

Forever death-recap fields were checked against Blizzard's public API documentation
and the client observations documented by GudaAddons/HeadHunter. The reader and
validation logic here are independently implemented; no HeadHunter files are bundled.
https://github.com/Gethe/wow-ui-source/blob/forever/Interface/AddOns/Blizzard_APIDocumentationGenerated/DeathRecapDocumentation.lua
https://github.com/GudaAddons/HeadHunter/blob/main/Detection/ForeverDeaths.lua

The ancient-book presentation is visually inspired by Overlord's warm fantasy
materials and restrained gold accents. No Overlord code or artwork is bundled.
The quiet parchment (Media/JournalPaper.tga) and the dark leather dialog frame
(Media/JournalDialog.tga) were generated with OpenAI's image tool and exported
as RGBA TGA textures. Both are distributed under GPLv3.

The campaign register's background (JournalBookSurface), title plaque,
medallion, settings and close buttons are independent layers. WoW renders the
title, labels, names and values at runtime. The original layered PNG assets
were generated for this project using OpenAI's image tool. They can be exported
to uncompressed RGBA TGA with art/campaign/export.py in the source repository.
The original campaign artwork is distributed under GPLv3.

The neutral silver medallion (Media/RelationNeutral.tga, 128x128 RGBA) was
generated using OpenAI's built-in image tool for 0.4.3 and is distributed
under the same GPLv3 terms. It identifies known neutral contacts.
